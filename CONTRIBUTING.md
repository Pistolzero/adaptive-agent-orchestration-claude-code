# Contributing

Thank you for helping improve this project. Please open an issue with the target behavior, expected evidence, failure case, and any compatibility concerns before proposing broad changes.

## Before a pull request

1. Keep all materials English-only and platform-specific instructions accurate for Claude Code.
2. Keep the entry Skill short. Put detailed discussion in `references/` and avoid reloading all docs in every task.
3. Never commit private logs, account credentials, authentication files, device identifiers, or user project data.
4. Preserve the exact failure/evidence contract, including reporting of recovered failures and unrun checks.
5. Do not claim runtime model/effort or token savings unless observed in a real compatible Claude Code host.
6. Run: `python -m unittest discover -s tests -v`.
7. Check third-party license terms before copying any code, instruction, or Skill.

By contributing, you agree that your contributions are made available under this project's MIT License.
