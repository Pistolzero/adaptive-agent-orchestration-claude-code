# Changelog

## 1.1.0 — 2026-11-12

- Documented Fable 5.2 as a preferred, user-selected manager and an explicit Opus fallback.
- Added one-owner routing for optional native Dynamic Workflows, with stage model precedence and cost guidance.
- Added a focused live compatibility matrix. Live Claude Code integration remains unverified in this release.

## 1.0.1 — 2026-11-12

- Clarified the per-task delegation cap in CONSERVE and UNKNOWN and the handling of unchanged permission and quota blockers.
- Made Windows installation check existing Skill and agent files before copying either.
- Documented validation from a clean Git export and added low-usage runtime regression scenarios.

## 1.0.0 — 2026-11-12

- Adapted the original evidence-first, budget-aware Codex orchestration policy to native Claude Code Skills.
- Added `.claude/agents/*.md` role presets for Haiku, Sonnet and optional Opus review, with explicit effort settings.
- Kept conservative quota behavior, manager-led routing, strict failure reports and independent verification.
- Added English-only installation, design, operations, security and publication documentation.
- Added static validation tests using Python standard library; no extra runtime dependency required.
- Did not change or replace the original Codex repository.
